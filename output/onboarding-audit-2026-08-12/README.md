# Onboarding audit — 2026-08-12

## Current path

1. About you — name and gifting persona.
2. Contacts — optional birthday import.
3. Preferences — relationships, budget, and style.
4. Invite five — blocking share gate.
5. Taste calibration — five required swipes.
6. Value recap — explanatory screen.
7. First save — blocking curated selection.
8. Sign in — required after guest onboarding.
9. Swipe tour.
10. Circles tour.
11. You tour — spotlight is misaligned.
12. Search tour — target is stale after the Home redesign.

## Recommended path

1. Intent + recipient + budget.
2. Three taste swipes.
3. Personalized results + first save.
4. Sign in to keep and sync the result.

Ask for contacts when a user first adds an occasion. Ask for one friend invite
after the first save. Teach tabs when they are first opened instead of using a
four-screen coach-mark sequence.

## Main finding

The current flow delays the first useful recommendation behind five setup
screens and then adds four instructional screens after sign-in. The taste deck
and first save are the strongest primitives; the contact import, five-invite
gate, value recap, and coach marks should not block activation.

The screenshots are simulator captures. VoiceOver, Dynamic Type, Switch
Control, Reduce Motion, permission-denial handling, and live network failures
still require device testing.
