## 2. The non-random gift basket formula

Slide text:

1. How to build a gift basket that doesn't feel RANDOM — the 4-part formula
2. Start with one anchor hobby—not a color
3. Add one daily upgrade she won't buy herself
4. Pick one scent or flavor she already loves
5. Add one comfort item for the texture
6. Include a plan: movie night, bath night, or Sunday reset
7. One hobby + one upgrade + one comfort + one plan = perfect

Caption:

> A good gift basket is not six random pink things. Use this formula: 1 anchor hobby + 1 daily upgrade + 1 comfort item + 1 plan to enjoy it. Save it before the next birthday panic. #giftbasket #giftideasforher #girlfriendgift #giftguide #giftinspo

## 3. How to make a $20 gift look expensive

Slide text:

1. How to make a $20 gift look ridiculously expensive — without pretending it cost more
2. Pick one color + repeat it everywhere
3. Split tiny items into separate mini presents
4. Handwrite the headline—skip the generic tag
5. Add a pun or callback only she will get
6. Include one handmade piece (even if you can't draw)
7. Cheap gift. Expensive amount of attention.

Caption:

> The difference between cheap and thoughtful is presentation plus specificity. Use one palette, create multiple small reveals, add handwriting, and finish with an inside callback. Save this before you wrap your next gift. #giftwrapping #giftideas #budgetgift #diygift #giftinspo
